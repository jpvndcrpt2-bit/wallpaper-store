# Wallpaper Store

Static wallpaper catalogue with Arabic, Persian and English interfaces.

## Hosting

In repository Settings → Pages, select **Deploy from a branch**, branch **main**, folder **/ (root)**, and Save.

The entry point is `index.html`. No build step is required.

Shop settings are saved locally in each visitor's browser; they do not update the published defaults. Set the shop WhatsApp number before accepting orders.
